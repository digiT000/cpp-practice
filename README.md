# Journey to Learn C++ and Try Game Development

My journey to learn C++ and try game development.

Based on the YouTube course **COMP 4300 - Intro to C++ Game Programming (2022-09)**:
[playlist](https://youtube.com/playlist?list=PL_xRyXins848nDj2v-TJYahzvs-XW9sVV)

## Goals

- Learn C++ fundamentals by following the course lectures
- Understand memory, pointers, and OOP
- Build small games and, eventually, a game engine project

## Structure

Each lecture gets its own folder with my notes and code.

```
cpp-practice/
├── introduction/   # first steps and basics
│   ├── part1/
│   └── part2/
└── ...             # lecture folders and projects as I go
```

## Build & Run

```bash
g++ -std=c++20 main.cpp -o main && ./main
```
